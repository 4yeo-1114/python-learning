📖 关于本项目

这是 Python 学习计划 Day 12 的 Flask Web 框架练习项目。

本项目演示了 Flask 的核心概念：

路由 (Routes)

使用 @app.route() 装饰器将 URL 路径映射到 Python 函数。

模板 (Templates)

使用 Jinja2 模板引擎，通过 render_template() 渲染 HTML。

你现在看到的页面就是通过 模板继承 创建的 — 它继承了 layout.html 的导航栏和页脚。

动态路由

路由可以包含动态部分，比如 /user/<name>：

  • /user/Alice
  • /user/Bob
  • /user/Charlie
